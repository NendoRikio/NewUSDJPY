# 📈 ForexAI Vision: USD/JPY & JPY/USD 5〜6時間後 Pips推論システム

過去チャート、テクニカル分析、最新ニュース、CME FedWatch（FOMC金利観測）を多変量AI頭脳でリアルタイムに統合解析し、**5〜6時間後にレートがどちらの方向に何Pips動くのか**を精密推定するプロフェッショナル向けFX支援アプリケーションです。

---

## 🌟 主な特徴

1. **5〜6時間後のPips変動幅・方向の精密推論**
   - **予測方向**: 🚀 上昇優勢 (UP) / 🔻 下落優勢 (DOWN) / ⚖️ レンジ・もみ合い (NEUTRAL)
   - **推定変動量**: 例 `+18.5 Pips` (想定レンジ: `+6.0 〜 +31.0 Pips`)
   - **ターゲット価格**: 到達見込み時刻（例: 5.5時間後）における予測レート
   - **モデル信頼度**: 各指標の一致度に基づくパーセンテージ（50%〜95%）
   - **エントリー指針**: 利確ターゲット（TP）および損切り目安（SL）のPips提示

2. **マルチファクター統合頭脳**
   - **過去チャート & テクニカル分析 (40%配分)**:
     - 1時間足 / 15分足 / 日足ローソク足
     - 移動平均線（SMA20, SMA50, SMA200, EMA12, EMA26）
     - ボリンジャーバンド（±1σ, ±2σ）
     - RSI(14) オシレーター
     - MACD & ヒストグラム
     - **ATR(14) 時間拡散モデル**: 5〜6時間の物理的なボラティリティ枠（最大想定Pips）を算出
     - 自動サポレジ検出（直近の上値抵抗線・下値支持線）
   - **CME FedWatch 金利観測 (30%配分)**:
     - 次回FOMCの利上げ・据え置き・利下げ確率をリアルタイム取得
     - ドル金利モメンタム（タカ派／ハト派バイアス）の定量評価
   - **最新為替ニュース速報 & センチメント (15%配分)**:
     - Google News RSS（日本語・英語）から最新のドル円・FRB・日銀動向を自動スクレイピング
     - ヘッドライン感情スコアリング（強気／弱気／中立）
   - **直近プライスモメンタム (15%配分)**:
     - 過去6時間の値動き速度とトレンド継続／反転判定

3. **未来予測コーン（ファンチャート）投影**
   - Plotlyによるリッチなローソク足チャート上に、直近現在値から5〜6時間後の予測ターゲットと「想定変動レンジ（信頼区間ファン）」をグラデーションで美しく描画。

4. **USD/JPY (ドル円) と JPY/USD (円ドル) の完全両対応**
   - ワンクリックで切り替え可能。
   - USD/JPY（1 pip = 0.01円 / 1銭）
   - JPY/USD（1 pip = 0.0001米ドル）

5. **Google Gemini AI による詳細ストラテジスト診断**
   - サイドバーにGemini APIキーを入力することで、機関投資家レベルの詳細な分析レポートを自動生成。
   - ※APIキーが未入力でも、内蔵の高度アルゴリズムが完全稼働するため、追加設定なしで即利用可能です。

## 🚀 起動方法

### 方法 1: ワンクリック起動（推奨）
フォルダ内の **`run_app.bat`** をダブルクリックするだけです。
自動的に黒いウィンドウが立ち上がり、ブラウザでアプリケーション画面が開きます。

### 方法 2: コマンドラインから起動
PowerShell または コマンドプロンプトで本フォルダを開き、以下を実行します：
```bash
python -m streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動で開きます。

## ⚙️ 5〜6時間後 Pips推論ロジックの仕組み

1. **ボラティリティ基礎枠（時間スケーリング則）**
   $$\sigma_{5.5h} \approx \text{ATR}_{1h} \times \sqrt{5.5} \times \text{市場セッション係数}$$
   - 東京市場（昼間）、欧州市場（夕方）、ロンドン/NY重複（夜間）で時間帯別のボラティリティ係数を適用。
   - これにより「今後5〜6時間で市場が動く現実的な物理的限界Pips」を導出します。

2. **方向性スコア（Direction Bias: -100 〜 +100）**
   - テクニカル（+40〜-40）+ FedWatch金利（+30〜-30）+ ニュース（+15〜-15）+ モメンタム（+15〜-15）を合算。

3. **推定Pipsの導出**
   - 総合スコアの符号と強度に応じて、ボラティリティ枠にドリフト係数を乗算して予想中央値Pipsを計算。
   - 信頼区間（±Pips）を上下に設けて、上振れ／下振れの想定レンジを提示します。
