# 📈 ForexAI Vision: USD/JPY & JPY/USD 5〜6時間後 Pips推論システム

過去チャート、高度テクニカル分析（一目均衡表・ADX/DMI・ストキャスティクス・ボリンジャーバンド等）、最新ニュース速報、CME FedWatch（FOMC金利観測）を多変量AI頭脳でリアルタイムに統合解析し、**5〜6時間後にレートがどちらの方向に何Pips動くのか**を精密推定するプロフェッショナル向けFX支援アプリケーションです。

---

## 🌟 主な特徴

1. **土日休場ギャップの完全カット（先週から連続したシームレスチャート）**
   - FX市場がクローズする土日や休業期間（約50時間）の空白を自動検出してスマートに除外。
   - 金曜クローズから今週月曜オープンまで、先週から途切れることなく連続した美しいローソク足チャートを描画。

2. **予想精度向上のための高度テクニカル分析 & 相場レジーム判定**
   - **一目均衡表（Ichimoku Kinko Hyo）**: 雲（先行スパンA・B）、基準線、転換線、三役好転/逆転シグナル。
   - **ADX & DMI (14期間)**: トレンドの「強さ」と「方向」を定量評価。強力なトレンド相場かレンジ相場かを自動認識。
   - **相場レジーム適応型スコアリング**: トレンド相場では順張りを重視し、レンジ相場ではオシレーター逆張りを優先して予想精度を大幅向上。
   - **Slow Stochastics (14, 3, 3)**: 短期的な反発・反落やゴールデンクロス/デッドクロスを検知。
   - **ボリンジャーバンドウォーク & スクイーズ検知**: バンド幅収縮からの急拡大やトレンド猛進を捕捉。
   - **プライスアクション分析**: 下ヒゲ/上ヒゲピンバーや包み足パターンのリアルタイム判定。
   - **マルチ指標オーバーレイ & オシレーター切替**: チャート上に一目雲・MA・BBを重ね合わせ、下段はRSI／ストキャスティクス／MACDをワンクリック切り替え可能。

3. **5〜6時間後のPips変動幅・方向の精密推論（起動時点をリアルタイム基準化）**
   - **分析起点**: アプリを起動または再推論ボタンを押した「現時点の日本時間（JST）」を基準点（0時間）として即座に算出。
   - **予測ターゲット時刻**: 現在時刻から正確に指定時間後（例: 5.5時間後）の目標時刻をヘッダー・カード・チャート上に明示。
   - **予測方向**: 🚀 上昇優勢 (UP) / 🔻 下落優勢 (DOWN) / ⚖️ レンジ・もみ合い (NEUTRAL)
   - **推定変動量**: 例 `+12.5 Pips` (想定レンジ: `+3.0 〜 +22.0 Pips`)
   - **ターゲット価格**: 到達見込み時刻における予測レート
   - **モデル信頼度**: 各指標の一致度に基づくパーセンテージ（50%〜95%）
   - **エントリー指針**: 利確ターゲット（TP）および損切り目安（SL）のPips提示

4. **USD/JPY (ドル円) と JPY/USD (円ドル) の完全両対応**
   - ワンクリックで切り替え可能。
   - USD/JPY（1 pip = 0.01円 / 1銭）
   - JPY/USD（1 pip = 0.000001米ドル）

5. **CME FedWatch & 為替ニュースセンチメント統合**
   - 次回FOMCの利上げ・据え置き・利下げ確率、政策スタンスを自動解析。
   - Google News RSSからドル円・為替ヘッドラインを即時解析し強気/弱気を判定。

6. **Google Gemini AI による詳細ストラテジスト診断**
   - サイドバーにGemini APIキーを入力することで、機関投資家レベルの詳細な分析レポートを自動生成。
   - ※APIキーが未入力でも、内蔵の高度アルゴリズムが完全稼働するため、追加設定なしで即利用可能です。

## 🚀 起動方法

### 方法 1: ワンクリック起動（推奨）
フォルダ内の **`run_app.bat`** をダブルクリックするだけです。
自動的に黒いウィンドウが立ち上がり、ブラウザでアプリケーション画面が開きます。

### 方法 2: コマンドラインから起動
PowerShell または コマンドプロンプトで本フォルダを開き、以下を実行します：
```bash
python -m streamlit run app.py
```

ブラウザで `http://localhost:8501` が自動で開きます。

## ⚙️ 5〜6時間後 Pips推論ロジックの仕組み

1. **ボラティリティ基礎枠（時間スケーリング則）**
   $$\sigma_{5.5h} \approx \text{ATR}_{1h} \times \sqrt{5.5} \times \text{市場セッション係数}$$
   - 東京市場（昼間）、欧州市場（夕方）、ロンドン/NY重複（夜間）で時間帯別のボラティリティ係数を適用。

2. **相場レジーム適応型スコアリング（Direction Bias: -100 〜 +100）**
   - **トレンド相場（ADX >= 25 / バンドウォーク時）**: トレンド追従指標（移動平均パーフェクトオーダー、一目雲抜け、DMI、MACD）の重みを大幅増強。RSIなどのオシレーター過熱を「モメンタム加速」と認識。
   - **レンジ相場（ADX < 20時）**: オシレーター（RSI、Slow Stochastics、ボリンジャーバンド逆張り、サポレジ反発）を重視。
   - FedWatch金利観測（±30pt）+ ニュース感情（±15pt）+ 直近モメンタム（±15pt）を合算。

3. **推定Pipsの導出**
   - 総合スコアの符号と強度に応じて、ボラティリティ枠にドリフト係数を乗算して予想中央値Pipsを計算。
   - 信頼区間（±Pips）を上下に設けて、上振れ／下振れの想定レンジを提示。
